# STP Brindisi Data Utility

> **Linguaggio:** Python 3  
> **Tipo:** Progetto Personale / Automation & Data Processing

Applicazione sviluppata in Python per l'estrazione, l'analisi e la gestione dei dati relativi agli orari e alle tratte del trasporto pubblico locale (STP Brindisi). Il progetto nasce dall'esigenza di strutturare e consultare rapidamente le informazioni sui trasporti in locale.

---

## Funzionalità

- **Data Parsing:** Elaborazione di flussi di dati strutturati/unstructured relativi agli orari dei bus.
- **Ricerca Rapida:** Logica di selezione e consultazione automatizzata per linee e fermate.
- **Esportazione & Formattazione:** Organizzazione delle informazioni per facilitarne l'integrazione o l'uso offline.

---

## Tech Stack

- **Python 3.x**
- Standard Library & Moduli per la gestione file/dati (es. `json`, `csv`, `urllib` / `requests`)

---

## Come Eseguire il Progetto

1. Assicurati di avere Python 3 installato sul tuo sistema:
```bash
   python --version
```

2. Clona il repository:
```bash
git clone [https://github.com/Sev3nB/stp-brindisi.git](https://github.com/Sev3nB/stp-brindisi.git)
cd stp-brindisi

```


3. Avvia lo script principale:
```bash
python main.py

```
